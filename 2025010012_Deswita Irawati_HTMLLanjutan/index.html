Selamat Datang

Ini adalah halaman utama dari kumpulan tugas praktikum HTML Lanjutan. Halaman ini menghubungkan seluruh latihan yang telah dibuat sesuai dengan spesifikasi modul praktikum Pemrograman Web 1.

Daftar Halaman Latihan Praktikum:

  • Latihan List (Praktik 1-3) - Mempelajari Unordered List, Ordered List, dan List Bersarang.
  • Latihan Table (Praktik 4-6) - Mempelajari tabel data mahasiswa, transaksi penjualan, Colspan, dan Rowspan.
  • Latihan Form (Praktik 7-16) - Mempelajari elemen form, berbagai jenis input, select, textarea, dan button.
  • Latihan Semantic HTML (Praktik 17-18) - Mempelajari penataan struktur tag semantic.
  • Mini Project Kegiatan (Praktik 19-20) - Integrasi List, Table, Form, dan Semantic HTML.
  • Latihan Debugging (Praktik 21) - Hasil perbaikan kesalahan struktur tag HTML.
