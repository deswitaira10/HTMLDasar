Profil Utama

Selamat datang di portal informasi mahasiswa. Halaman ini dirancang menggunakan elemen-elemen Semantic HTML untuk menyusun struktur dokumen web yang bermakna dan rapi.

Kegiatan Akademik

Pengalaman Belajar HTML Lanjutan

Pada modul kali ini, saya mempelajari berbagai elemen penting seperti pembuat daftar (list), tabel untuk menyajikan data, formulir untuk input data pengguna, hingga penataan struktur semantic.

Persiapan Mini Project

Seluruh materi yang dipelajari digabungkan ke dalam sebuah mini project pendaftaran kegiatan mahasiswa yang menghubungkan seluruh halaman HTML.

Informasi Tambahan (Side Note)
